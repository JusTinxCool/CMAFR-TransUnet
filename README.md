# CMAFR-TransUnet
## Code Availability

This repository provides the project structure and partial implementation of **CMAFR-TransUNet**, including:

- Training scripts
- Data preprocessing scripts
- Basic configuration files

The core model implementation and complete experimental code are not publicly released at this stage. Additional code will be uploaded progressively after the manuscript is accepted for publication.

The complete implementation is available from the corresponding author upon reasonable request.


## Dataset Availability

The experiments were conducted on two publicly available medical image segmentation datasets: **Synapse** and **ACDC**.

### 1. Official Dataset Sources

The original datasets can be accessed through their official providers:

- **Synapse (Multi-Atlas Labeling Beyond the Cranial Vault):**  
  https://www.synapse.org/Synapse:syn3193805/wiki/217789

- **ACDC (Automated Cardiac Diagnosis Challenge):**  
  https://www.creatis.insa-lyon.fr/Challenge/acdc/databases.html

### 2. Preprocessed and Project-Provided Data

For convenience, the following data resources are provided by the official [TransUNet repository](https://github.com/Beckschen/TransUNet):

- **Synapse/BTCV Preprocessed Dataset:**  
  https://drive.google.com/drive/folders/1ACJEoTp-uqfFJ73qS3eUObQh52nGuzCd

- **ACDC Dataset (TransUNet Project Resources):**  
  https://drive.google.com/drive/folders/1KQcrci7aKsYZi1hQoZ3T3QUtcy7b--n4

These links are provided for convenient dataset access and research reproducibility. The datasets are not redistributed in this repository. Users should comply with the respective data providers' access conditions and usage policies.
